Configuration

Set the server URL and credentials for your environment. Enable only the features your application needs.

Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

import { CloudflareApplicationDeliverySDK } from '@voxgig-sdk/cloudflare-application-delivery-sdk'

const client = new CloudflareApplicationDeliverySDK({ apikey: process.env.CLOUDFLARE_APPLICATION_DELIVERY_APIKEY })
