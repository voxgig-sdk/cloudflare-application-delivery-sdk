Property Type Required Description

check_regions array of enum: WNAM, ENAM, WEU, EEU, NSAM, SSAM, ... No A list of regions from which to run health checks. Null means Cloudflare will pick a default region.
consecutive_fails integer No The number of consecutive fails required from a health check before changing the health to unhealthy.
consecutive_successes integer No The number of consecutive successes required from a health check before changing the health to healthy.
description string No A human-readable description of the health check.
http_config object No Parameters specific to an HTTP or HTTPS health check.
http_config.allow_insecure boolean No Do not validate the certificate when the health check uses HTTPS.
http_config.expected_body string No A case-insensitive sub-string to look for in the response body. If this string is not found, the origin will be marked as unhealthy.
http_config.expected_codes array of string No The expected HTTP response codes (for example "200") or code ranges (for example "2xx" for all codes starting with 2) of the health check.
http_config.follow_redirects boolean No Follow redirects if the origin returns a 3xx status code.
http_config.header object No The HTTP request headers to send in the health check. It is recommended you set a Host header by default. The User-Agent header cannot be overridden.
http_config.method enum: GET, HEAD No The HTTP method to use for the health check.
http_config.path string No The endpoint path to health check against.
http_config.port integer No Port number to connect to for the health check. Defaults to 80 if type is HTTP or 443 if type is HTTPS.
interval integer No The interval between each health check. Shorter intervals may give quicker notifications if the origin status changes, but will increase load on the origin as we check from multiple locations.
name string Yes A short name to identify the health check. Only alphanumeric characters, hyphens and underscores are allowed.
retries integer No The number of retries to attempt in case of a timeout before marking the origin as unhealthy. Retries are attempted immediately.
suspended boolean No If suspended, no health checks are sent to the origin.
tcp_config object No Parameters specific to TCP health check.
tcp_config.method enum: connection_established No The TCP connection method to use for the health check.
tcp_config.port integer No Port number to connect to for the health check. Defaults to 80.
timeout integer No The timeout (in seconds) before marking the health check as failed.
type string No The protocol to use for the health check. Currently supported protocols are 'HTTP', 'HTTPS' and 'TCP'.
